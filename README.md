# Pousse 🌱

Pousse est le carnet de bord de vos plantes d'intérieur.

- **Identifiez** une plante en la prenant en photo.
- **Recevez un rappel** au bon moment pour l'arroser, la rempoter ou la fertiliser.
- **Adaptez l'arrosage à la météo** de chez vous (luminosité, humidité, saison).
- **Suivez sa croissance** avec un journal photo.
- **Pousse+** (abonnement) : plantes illimitées, diagnostic des maladies, sans publicité.

## Lancer le projet

```bash
npm install
npx expo start
```
